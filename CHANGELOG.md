# Changelog

## 1.0.0 — 2026-11-06

- Bound collection validation work and preserve complete-form validation semantics in Filament.
- Align checkbox presence and temporal ranges with native browser controls.
- Improve invalid-input redisplay, theme contrast, localization, and reproducible stylesheet builds.
- Add regression, browser accessibility, minimum-dependency, formatting, and static-analysis checks.


- Immutable field schemas for Laravel 12/13 and PHP 8.3+.
- Laravel validation, nested field paths, exact decimal strings and numeric bounds, finite JSON values, and sensitive-value controls.
- Accessible Tailwind 4 Blade forms with publishable views and compiled CSS.
- CSV import/export with validation, configurable limits, JSON scalar preservation, and spreadsheet formula escaping.
- Optional Filament 5 form components and PDF reports through DocSign.
- Indexed schema construction and reusable validation rule maps.
